## 👋 About Me

Hi, I'm **Sanjeev Gupta**, a Full Stack Developer, educator, and BCA student from India.

I have been coding for approximately **5 years**, exploring web technologies, developing applications, and continuously improving my programming skills.

Currently, I work as a **Teacher and Full Stack Developer at Compify Institute**, where I combine my passion for software development with teaching and helping students understand programming concepts.

Although I haven't been very active on GitHub in the past, I'm now focusing on building a stronger public portfolio, sharing my projects, and becoming more consistent with my contributions.

I believe that great developers never stop learning, and great teachers never stop being students.

### 🚀 What I Do

- 💻 Build modern and responsive web applications.
- ⚛️ Develop interactive user interfaces using React and JavaScript.
- ⚙️ Work on backend development using Node.js and Express.js.
- 🗄️ Explore database design, SQL, MongoDB, and Redis.
- 🔧 Use Git and GitHub for version control and project management.
- 🎓 Teach programming and help students develop practical coding skills.
- 📚 Learn new technologies and improve my development workflow.

### 🎯 My Goals

- Publish more practical projects on GitHub.
- Improve my GitHub activity and open-source participation.
- Develop complete frontend and backend applications.
- Write clean, maintainable, and reusable code.
- Strengthen my knowledge of databases, APIs, and application architecture.
- Continue growing as both a developer and an educator.
